# Frontend Beginner — Code Samples & Versions

Companion code samples, step-by-step exercises, and version snapshots for the **`frontend-beginner`** series on YouTube by **Wael Habbal** (`@waelhabbaldev`).

> **"Learn how it works. Build what's next. Keep Coding."**

---

## About This Repository

This repository holds beginner-friendly frontend and JavaScript examples used during lessons and streams so learners can:

- Follow along with each episode without typing everything from scratch.
- Compare updated versions or refactored samples across lessons.
- Run and experiment with small scripts to see how JavaScript behaves under the hood.

---

## How to Run the Samples

1. **Clone or download the repository:**
```bash
git clone [https://github.com/YOUR-USERNAME/frontend-beginner.git](https://github.com/YOUR-USERNAME/frontend-beginner.git)
cd frontend-beginner

```


2. **Run JavaScript files:**
* **Browser:** Open an `index.html` file that loads the script, or paste the snippet into your browser's **Developer Console** (`F12` / `Cmd + Option + I`).
* **Node.js / Bun (if installed):** Run a file directly from your terminal:
```bash
node path/to/sample.js

```
